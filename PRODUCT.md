# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose
NovoDS Studio manages a local DS200 digital signage network, media, playlists, and recurring schedules.

## Users
Repository-inferred: signage operators managing LAN-connected display players. Desktop-first operation is the working assumption following the user's request to continue, with mobile web support retained.

## Capabilities and Constraints
Preserve device discovery, snapshots, remote controls, media upload and preview, playlist and schedule editing, publishing, developer diagnostics, XML export, and single-entry schedule deletion. Real device state must never be simulated. Preserve confirmation, revision checks, cancellation, readback verification, and errors. Device schedule timezone and raw bound encodings are unknown. Local schedules and device schedules are distinct.

## Brand Commitments
Keep NovoDS Studio and DS200 terminology. User requested a modern SaaS redesign, especially View Device Schedule, without breaking working functions.

## Evidence on Hand
Existing app and API code, docs/, test/, and local running application. No invented product claims or sample device data.
